# РИД Кольца HA

Android-приложение для измерения диаметров колец преципитации на окрашенных пластинках
**радиальной иммунодиффузии (SRID/РИД)** и количественного определения **гемагглютинина (HA)**.

## Возможности

- Фото пластинки с камеры телефона или из галереи (а также «Поделиться → РИД Кольца HA»).
- **Автоматический поиск кольца** по нажатию в центр лунки:
  144 радиальных луча → сглаженный профиль яркости → внешняя граница зоны преципитации
  (внутренний край лунки и соседние кольца отбрасываются) → робастная аппроксимация
  окружности (LMedS + МНК Косы с отбрасыванием выбросов) → несколько итераций с уточнением центра.
  Точность на синтетических изображениях — лучше 0,6 px.
- Работает и для тёмных (окрашенных Кумасси) колец на светлом фоне, и для светлых на тёмном;
  канал цвета выбирается автоматически по максимальному контрасту (для синего красителя — красный).
- Ручная правка: перетаскивание центра и края окружности, кнопка «Уточнить».
- **Калибровка масштаба** по двум точкам на линейке → диаметры в мм.
- Для каждого кольца: стандарт/образец, название, относительная доза (`1`, `0.75`, `1:2`, `25%`);
  разведения по умолчанию подставляются автоматически (1; 0.75; 0.5; 0.25).
- **Расчёт HA**:
  - стандартная кривая: площадь зоны `S = π·d²/4` (опционально `π·(d² − d₀²)/4`) линейно от
    концентрации стандарта; HA образца = C(S) / доза, среднее ± SD, CV, флаг экстраполяции;
  - метод **параллельных линий** (как в фармакопейном SRID): `ln S` от `ln дозы`, общий наклон,
    `HA = HA_ст · exp(M)`, отношение наклонов для проверки параллельности.
- Графики, таблицы, экспорт в **CSV** (открывается в Excel) и размеченного снимка (JPEG).
- Состояние сохраняется автоматически.

## Как снимать

1. Пластинка на ровном светлом фоне (лайтбокс идеален), камера строго параллельно пластинке.
2. Рядом линейка — для калибровки масштаба (для расчёта HA масштаб не обязателен, он нужен для
   мм и вычитания лунки).
3. Без бликов; кольцо должно занимать хотя бы 40–50 px в диаметре.

## Сборка

APK собирается автоматически в GitHub Actions (вкладка **Actions → Android build → Artifacts →
`srid-ha-apk`**). Release-APK подписан debug-ключом и устанавливается напрямую (разрешите установку
из неизвестных источников).

Локально (Android Studio или JDK 17 + Android SDK):

```bash
./gradlew :app:assembleRelease          # APK: app/build/outputs/apk/release/
./gradlew -PcoreOnly :core:test         # тесты алгоритмов без Android SDK
```

## Структура

- `core/` — чистый Kotlin без зависимостей от Android: поиск колец (`RingDetector`),
  аппроксимация окружности (`CircleFit`), расчёт анализа (`AssayCalculator`), CSV. Покрыто тестами.
- `app/` — Android-интерфейс: `PlateView` (зум, разметка), `MainActivity`, `ResultsActivity`.

Минимальная версия Android — 8.0 (API 26).
