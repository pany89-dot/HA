# РИД Кольца HA

Android-приложение для измерения диаметров колец преципитации на окрашенных пластинках
**радиальной иммунодиффузии (SRID/РИД)** и количественного определения **гемагглютинина (HA)**.

## Возможности

- Фото пластинки с камеры телефона или из галереи (а также «Поделиться → РИД Кольца HA»).
- **Автопоиск всех колец** сразу после открытия фото: вычитание фона, порог Оцу, заполнение лунок,
  дистанционное преобразование (разделяет соприкасающиеся зоны), затем точная подгонка каждой
  границы: 144 радиальных луча → внешний край зоны преципитации → робастная аппроксимация
  окружности (LMedS + МНК с отбрасыванием выбросов). В каждой зоне находится и **лунка**.
  Точность на синтетических пластинках — лучше 0,7 px для зон и 0,8 px для лунок.
- **Масштаб по диаметру лунок**: мм/px = диаметр штампа / медианный диаметр найденных лунок
  (с CV). Запасной вариант — ручная калибровка по двум точкам.
- **Схема пластинки**: сетка строк × столбцов, стандарт и образцы, разведения, повторы
  (рядом или повтором серии), заполнение по строкам или столбцам, правка отдельных лунок.
  Найденные кольца раскладываются по сетке и получают стандарт/образец и дозу автоматически.
- Ручная правка: добавление нажатием (авто или вручную), перетаскивание центра и края, «Уточнить».
- **Расчёт HA — оба метода**:
  - стандартная кривая: площадь зоны `S = π·d²/4` (опционально `π·(d² − d₀²)/4`) линейно от
    концентрации стандарта; HA образца = C(S) / доза, среднее ± SD, CV, флаг экстраполяции;
  - **параллельные линии**: `ln S` от `ln дозы`, общий наклон, `HA = HA_ст · exp(M)`,
    отношение наклонов для проверки параллельности.
- **PDF-протокол**: препарат, серия, штамм, стандартный антиген (серия, HA), антисыворотка,
  дата, исполнитель; результаты обоими методами, графики, размеченный снимок, таблица измерений,
  место для подписи.
- Экспорт в **CSV** (Excel) и размеченного снимка (JPEG). Текущая работа сохраняется автоматически.

## Как снимать

1. Пластинка на ровном светлом фоне (лайтбокс идеален), камера строго параллельно пластинке.
2. Без бликов; кольцо должно занимать хотя бы 40–50 px в диаметре.
3. В «Параметрах анализа» укажите диаметр штампа лунки — по нему считается масштаб.

## Сборка

APK собирается автоматически в GitHub Actions (вкладка **Actions → Android build → Artifacts →
`srid-ha-apk`**). Release-APK подписан debug-ключом и устанавливается напрямую (разрешите установку
из неизвестных источников).

Локально (Android Studio или JDK 17 + Android SDK):

```bash
./gradlew :app:assembleRelease          # APK: app/build/outputs/apk/release/
./gradlew -PcoreOnly :core:test         # тесты алгоритмов без Android SDK
```

## Структура

- `core/` — чистый Kotlin без зависимостей от Android: поиск всех колец (`PlateScanner`),
  граница одного кольца (`RingDetector`), окружность (`CircleFit`), сетка и схема
  (`GridAssign`, `PlateTemplate`), расчёт анализа (`AssayCalculator`), CSV. Покрыто тестами,
  в том числе на реальных фото пластинок (`core/src/test/resources/plates/`, `RealPlateTest`):
  на каждой сборке проверяется, что на них находятся все 32 кольца с эталонными размерами.
- `app/` — Android-интерфейс: `PlateView` (зум, разметка), `MainActivity`, `TemplateActivity`
  (схема пластинки), `ResultsActivity`, `PdfReport` (протокол).

Минимальная версия Android — 8.0 (API 26).
